# Restaurant Management System — Python / PyQt5 Desktop Application

A modular restaurant operations application built with **Python, PyQt5, SQLite, PyQtChart, ReportLab, and FPDF**.

## What It Demonstrates

This project is an earlier desktop-engineering project focused on business workflows and event-driven GUI development.

Implemented areas include:

- employee management
- menu and product management
- stock management
- order workflows
- dashboard charts
- SQLite persistence
- PDF/report generation

## Technology Stack

| Area | Technology |
|---|---|
| Language | Python |
| Desktop UI | PyQt5 |
| Charts | PyQtChart |
| Database | SQLite |
| Reporting | ReportLab, FPDF |
| Images | Pillow |

